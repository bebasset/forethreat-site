01Coverage

What we test

Mapped to the OWASP API Security Top 10 (2023), with most of the time spent on authorization and business logic.

Authorization

  • BOLA / IDOR: reading or modifying other users' or tenants' objects by changing an ID
  • Function-level authorization: calling admin or internal endpoints as a normal user
  • Object property-level authorization: mass assignment and excessive data exposure
  • Unprotected access to sensitive business flows such as checkout, invites, and exports

Authentication & tokens

  • JWT signature, algorithm, expiry, and claim handling
  • OAuth 2.0 / OIDC flows, API keys, and refresh-token behavior
  • Rate limiting, resource consumption, and brute-force controls
  • Session invalidation on logout, password change, and role change

GraphQL-specific

  • Introspection and schema exposure
  • Per-field and per-resolver authorization
  • Batching/aliasing abuse and query-depth limits
  • Injection through arguments and variables

Server-side & configuration

  • Injection (SQL, NoSQL, command) and SSRF via webhook or URL fields
  • Improper inventory: old API versions and undocumented endpoints
  • CORS, verbose errors, and debug endpoints
  • Unsafe consumption of third-party APIs
